# GPS Art 跑圖

GPS Art（跑圖）的路線預覽與陪跑頁原型。

先看全部路線的形狀，選定一條之後，**從你現在站的位置開始跑圖**，
即時算出跑到哪裡、還剩多少、偏離多少；結束時跳出一張總結卡片。
**沒有導航、沒有轉彎提示、沒有語音** —— 它回答的是「這條圖我要不要跑、跑到哪了」，
不是「下一步該往哪走」。

---

## 快速開始

```bash
npm install
npm run dev          # http://localhost:5173

npm run build        # typecheck + 打包到 dist/
npm run preview      # 預覽打包結果（會開 --host）
```

開發檢查（用本機 Chrome 開頁面、印出狀態並截圖，需 macOS Chrome）：

```bash
npm run check -- http://localhost:5173/ shot.png <mode>
# mode: browse | preview | run | sim | second | desktop | gps | gps-start | gps-mid
```

## 流程

```
① 瀏覽全部路線 ──點卡片──▶ ② 確認起跑點 ──開始跑圖──▶ ③ 跑圖中 ──結束跑圖──▶ 總結 ──完成──▶ ①
```

| 階段 | 地圖 | 資訊卡 |
|---|---|---|
| ① 瀏覽 | 一次畫出所有路線，自動框住全部範圍 | 路線清單：名稱、距離、`距你 340 m` |
| ② 預覽 | 起點就是你目前的位置，選中的路線高亮、其他淡出 | 起跑點資訊、起跑方式、開始跑圖 |
| ③ 跑圖 | 規劃路線退成灰藍色當對照，橘色畫出實際移動軌跡 | 已完成 %、剩餘距離、偏離距離、狀態燈 |
| ④ 總結 | 回到全部路線 | 本次軌跡圖、完成 %、時間、實際距離、平均速度、平均偏離 |

### 起跑點

- **最近點切入**：從你站的位置起跑，先走到路線上最近的切入點（接駁線會一起畫出來），
  再沿路線跑。閉環會把路線在切入點切開再接回該點，所以跑完一圈剛好回到切入點。
起跑不會把你「瞬移」到路線上：起跑瞬間一定在你當下的 GPS 位置，
已完成 % 從切入點才開始算（接駁段只算距離、不算進度）。

## 地圖上的線

| 線 | 顏色 | 意思 |
|---|---|---|
| 實際移動軌跡 | 橘色實線 + 白邊 | GPS 真的走出來的路（未達 2m 的抖動濾掉，跳躍 > 200m 自動斷段） |
| 規劃路徑 | 灰藍色實線 | 這次要跑的路線（含接駁段；預覽時是路線主色） |
| 原路徑未跑段 | 深灰實線 | 切入點之前「不會跑到」的前段 |
| 原起點標記 | 灰色膠囊「原 X%」 | 原始 GPX 起點，X% 是切入點在**原路徑**上的位置 |

百分比一律用文字表示：資訊卡 `離路線 24 m，路線 50% 處接上`、地圖 `原 50%`。

## 結束跑圖的總結

按下「結束跑圖」後跳出總結卡片，背後的地圖同步回到全部路線。

| 項目 | 算法 |
|---|---|
| 軌跡圖 | 橘色＝實際走過的路（白邊），淡灰＝規劃路線，綠點起點、黑點終點 |
| 完成 % | 以路線本身計算，不含接駁段 |
| 時間 | 開始跑圖 → 結束跑圖 的實際經過時間 |
| 實際距離 | 軌跡逐點累加，不是路線長度 |
| 平均速度 | 實際距離 ÷ 時間（km/h） |
| 平均偏離 | 每次定位到路線的垂直距離平均（小於 GPS 精度的誤差視為 0） |

完全沒移動時顯示「這次沒有移動紀錄」。按「完成」、點背景或按 `Esc` 都能關閉。

## 模擬位置（不用出門）

右上角「模擬」打開後會出現一顆假 GPS 藍點，**用 WASD 自由移動**：

| 操作 | 桌機 | 手機 |
|---|---|---|
| 移動 | `W A S D` | 畫面右側虛擬十字鍵（長按） |
| 回到線上 | 「吸附回路線」 | 同左 |

- 二維自由移動，可以直接走出 20m / 50m / 300m 的偏離門檻；速度固定、沒有加速鍵。
- 假定位精度固定 8m，所以「偏離距離」不會被誤差吃掉。

## 手機測試

**Geolocation 只在 HTTPS 或 localhost 可用。** 手機連 `http://192.168.x.x:5173`
會直接拿不到定位。用 tunnel 取得 https 網址：

```bash
npx cloudflared tunnel --url http://localhost:5173
```

在手機開啟它印出的網址，允許定位後藍點就會出現。

> iOS：螢幕鎖定後 `watchPosition` 會被暫停（瀏覽器限制，不是 bug）；
> 建議搭配螢幕恆亮，正式版再加 Wake Lock。

## 換路線

1. 把 GPX 放進 `public/gpx/`，**檔名用英文**（中文檔名在 URL 上容易出編碼問題）
2. 在 `src/routes.ts` 加一筆：

```ts
{ id: 'cat', name: '貓', note: '市區街道｜封閉環形', color: '#e11d48', file: './gpx/cat.gpx' }
```

GPX 需為 WGS84（Strava 匯出的就是），支援 `trkpt` 與 `rtept`（不支援 `wpt`），
沒有時間戳也能用。`note` 寫形狀或路況，不要寫特定行政區，這個站要能放任何城市的 GPX。

底圖是 `src/map.ts` 的 `STYLE_URL`（目前 [OpenFreeMap](https://openfreemap.org) positron），
換一行就能換圖磚。

## 專案結構

```
index.html            版面骨架（地圖 + 頂部 + 底部資訊卡 + 虛擬十字鍵 + 總結卡片）
src/
  main.ts             狀態機（browse / preview / run）、UI 綁定、模擬與結束總結
  geo.ts              投影、偏離、進度、路線旋轉、座標工具（核心）
  gpx.ts              GPX → 座標陣列（自己寫 DOMParser，沒裝套件）
  map.ts              MapLibre 圖層與標記、fitBounds
  nav.ts              watchPosition 包裝與錯誤分類
  routes.ts           路線清單
  style.css           手機優先樣式
public/gpx/           dino.gpx（小恐龍 4.85km）、dino2Half.gpx（迅猛龍 6.25km）
scripts/check.mjs     開發用截圖與狀態檢查
```
